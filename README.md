# حسابدار جامع — بستهٔ PWA (برای ساخت اپلیکیشن با PWABuilder)

این پوشه یک **اپلیکیشن وب پیشرو (PWA)** کامل و آفلاین است که آماده‌ی آپلود در گیت‌هاب و
ساخت اپلیکیشن اندروید با سایت [pwabuilder.com](https://www.pwabuilder.com) است.

> اگر این پوشه را به‌صورت فایل zip دریافت کرده‌اید، **اول آن را روی گوشی یا کامپیوتر
> Extract/استخراج کنید** — گیت‌هاب فایل zip را مستقیم قبول نمی‌کند، باید فایل‌های داخلش
> را جداگانه بارگذاری کنید.

## محتویات پوشه
- `index.html` — کل برنامه (تک‌فایلی، بدون هیچ وابستگی اینترنتی)
- `manifest.json` — مشخصات اپ (نام، آیکون‌ها، **قفل حالت ایستاده/عمودی**)
- `sw.js` — Service Worker برای کارکرد کاملاً آفلاین
- `icons/` — همهٔ آیکون‌های لازم (ساخته‌شده از آیکونی که فرستادید)

## مرحله ۱ — بارگذاری در گیت‌هاب
1. وارد [github.com](https://github.com) شوید و یک ریپازیتوری جدید بسازید (Public باشد؛
   نامی مثل `hesabdar-jame`).
2. داخل ریپازیتوری، از دکمهٔ **Add file → Upload files** استفاده کنید.
3. **تمام فایل‌ها و پوشهٔ `icons` را با همین ساختار** (نه در پوشه‌ای اضافه) در ریشهٔ
   ریپازیتوری بارگذاری کنید — یعنی بعد از آپلود باید مسیر `index.html`، `manifest.json`،
   `sw.js` و `icons/icon-512.png` مستقیماً در ریشه باشند.
4. دکمهٔ **Commit changes** را بزنید.

## مرحله ۲ — فعال‌سازی GitHub Pages
1. در ریپازیتوری به **Settings → Pages** بروید.
2. زیر «Build and deployment»، گزینهٔ Source را روی **Deploy from a branch** بگذارید.
3. Branch را `main` (یا `master`) و پوشه را `/ (root)` انتخاب و **Save** کنید.
4. چند دقیقه صبر کنید. آدرسی شبیه این فعال می‌شود:
   `https://USERNAME.github.io/hesabdar-jame/`
   (به‌جای USERNAME نام کاربری گیت‌هاب خودتان می‌آید)
5. این آدرس را در مرورگر باز کنید و مطمئن شوید برنامه درست بالا می‌آید.

## مرحله ۳ — ساخت اپلیکیشن با PWABuilder
1. وارد [pwabuilder.com](https://www.pwabuilder.com) شوید.
2. آدرس GitHub Pages مرحلهٔ قبل را در کادر وارد و **Start** را بزنید.
3. PWABuilder اطلاعات (نام، آیکون، حالت ایستاده) را خودکار از `manifest.json` می‌خواند.
4. به تب **Android** بروید و روی **Generate Package** بزنید (Package ID را می‌توانید
   خودتان تعیین کنید، مثلاً `ir.myshop.hesabdarjame`).
5. فایل نهایی را دانلود کنید — یک فایل `.aab` (برای بازار/Google Play) و همچنین گزینهٔ
   دریافت `.apk` مستقیم برای نصب دستی وجود دارد.

## نکات مهم
- **آفلاین بودن**: بعد از اولین بار باز شدن برنامه (چه در مرورگر چه در اپ نصب‌شده)،
  Service Worker کل برنامه را ذخیره می‌کند و از آن به بعد بدون اینترنت هم کار می‌کند.
- **قفل حالت ایستاده**: در `manifest.json` مقدار `"orientation": "portrait"` تنظیم شده و
  PWABuilder همین را در اپ اندروید اعمال می‌کند؛ به‌عنوان یک لایهٔ اطمینان اضافه، اگر با
  هر روش دیگری گوشی افقی چرخانده شود، پیام «لطفاً گوشی را عمودی نگه دارید» نمایش داده
  می‌شود به‌جای بهم‌ریختن صفحه.
- اگر بعداً محتوای `index.html` را تغییر دادید، همان فایل را دوباره در گیت‌هاب آپلود
  (Commit) کنید؛ چون Service Worker نسخهٔ جدید را به‌طور خودکار در پس‌زمینه دریافت و در
  بازدید بعدی جایگزین می‌کند.
